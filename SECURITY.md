# Security policy

Please do not report a suspected vulnerability in a public issue. Send a
private report to the maintainers through the security contact configured for
the GitHub repository, including a description, affected package and version,
reproduction steps, impact, and a proposed mitigation if available.

Do not include secrets, customer data, internal hostnames, or private source in
the report. The repository's public-surface and Gitleaks checks are required
for every change; a passing check does not replace responsible disclosure.

Supported versions are the latest release on the `main` branch. Security fixes
may be released as patch versions and documented in `CHANGELOG.md`.
