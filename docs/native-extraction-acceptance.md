# Native 前后端拆包验收

本轮将 Studio 工作区的三个完整 Native 包同步至 `codex/native-extraction`，包含此前已在 Studio 实现的能力改进。精确源码边界、源提交及工作区变更标记见 `native-source-snapshot.json`。

后端的子任务装配、权限与工作区绑定、环境和模型输入构造已移入 Node 包；任务时间线、事件投影、终端、子智能体与文件侧栏、运行面板及 Native A2A 交互已移入 UI 包。Studio 保留产品预设、资源与凭证、鉴权、会话和页面端口适配。三个包均不导入 Studio 实现；UI 使用宿主 React。

## 验收范围

验证使用实际 npm 归档和受控模型，覆盖包独立性、协议与恢复、前端渲染和 Host 接入契约；不代表本轮重新完成真实模型质量评测或浏览器视觉对比。UI 拆包保留已有交互行为，没有借此重新设计界面。

产物可以通过 npm 安装本地 `.tgz`，尚未发布 npm registry。本轮不实现 Python 高代码 SDK、不部署云端，也不合并 main。
